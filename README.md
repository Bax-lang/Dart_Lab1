// Ответы на вопросы

1. **Чем статическая типизация Dart отличается от Python? Какое практическое преимущество она даёт?**
   В Dart тип каждой переменной проверяется на этапе компиляции до запуска программы, тогда как в Python типы определяются динамически во время выполнения. Практическое преимущество в том, что компилятор заранее находит ошибки несовместимости типов, предотвращая падение программы в рантайме.

2. **Что означает `String?`? Чем отличается от `String`?**
   `String` — это тип строки, который гарантированно не может принимать значение `null`. `String?` (nullable-тип) означает, что переменная может хранить либо строку, либо `null`, и перед вызовом методов у неё компилятор требует выполнить проверку на `null`.

3. **Зачем в Dart `final`, если в Python можно просто договориться не менять переменную?**
   В крупных проектах устные договорённости легко нарушить по невнимательности. Ключевое слово `final` заставляет компилятор строго контролировать неизменяемость ссылки после первого присваивания и выдавать ошибку при попытке перезаписать переменную.

4. **Чем именованный параметр `{required String name}` отличается от позиционного? Приведите пример вызова.**
   Именованный параметр передаётся с явным указанием его имени при вызове функции, поэтому порядок аргументов не имеет значения, а модификатор `required` делает его обязательным. Позиционный параметр передаётся строго на своём месте без указания имени.
   Пример вызова: `describePet(name: 'Барсик', age: 3);`
